Arctos-Themed Slack Bot

My first-ever Slack bot that is designed to, so far, introduce itself, check latency, retrieve cat facts, tell jokes, and roll dice.

Commands:
- `/arctos`         - The bot will introduce itself!
- `/arctos-ping`    - Checks the ping!
- `/arctos-catfact` - Learn a cat fact from ArctosBOT!
- `/arctos-joke`    - Receive a joke from ArctosBOT!
- `arctos-diceroll [dice_notation]` - Roll a dice!
- `/arctos-help` - Receive assistance navigating the bot's commands!

Feel free to demo this project!
