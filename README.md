# Arctos-Themed Slack Bot

My first-ever Slack bot that is designed to, so far, introduce itself, check latency, retrieve cat facts, tell jokes, and roll dice. I started this project during the final few weeks of the school year, and I spent some time each and every single day adding newer commands such as the diceroll and the introduction commands! 

## Here are some of the commands that the bot will respond to:
- `/arctos`         - The bot will introduce itself!
- `/arctos-ping`    - Checks the ping!
- `/arctos-catfact` - Learn a cat fact from ArctosBOT!
- `/arctos-joke`    - Receive a joke from ArctosBOT!
- `/arctos-diceroll [dice_notation]` - Roll a dice!
- `/arctos-help` - Receive assistance navigating the bot's commands!
